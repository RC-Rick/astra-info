## astra-info - скрипт вывода краткой информации об `Astra Linux`
- Автор разработки `RC-Rick`
- Версия `0.1`
- Разработано для astraops.ru
***
## Для чего скрипт?
Для того, чтобы выводить полезную информацию о системе одним запуском.
***
## Скрипт выводит:
- Параметры системы
  - Время создания отчета
  - Имя хоста
  - Операционная система
  - Версия Astra
  - Обновление / сборка Astra
  - Версия расширения Astra
  - Сборка расширения Astra
  - Версия Debian
  - Ядро
  - Архитектура
  - Инициализация
  - Время загрузки
  - Время работы
  - Средняя нагрузка
  - Залогиненные пользователи
  - Процессы
  - Виртуализация
- Оборудование / Ресурсы
  - Производитель
  - Продукт
  - Серийный номер
  - Производитель BIOS
  - Версия BIOS
  - Модель процессора
  - Количество ядер процессора
  - Общий объем памяти
  - Используемый объем памяти
  - Доступный объем памяти
  - Общий объем подкачки
  - Используемый объем подкачки
- Сведения о сети
  - Шлюз по умолчанию
  - DNS-серверы
  - Глобальные IPv4
  - Глобальные IPv6
- Сетевые интерфейсы
  - Интерфейс
- Использование файловой системы
  - Файловая система
- Файл подкачки
  - Свапфайл
- Вошедшие пользователи
  - Пользователь
- Топ-5 по процессорам
  - PID
- Топ-5 по памяти
  - PID
***

- Запуск из директории, где лежит скрипт
```bash
sudo bash astra-info.sh
```
